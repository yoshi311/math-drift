# MATH DRIFT ― 峠の数学エンジニア

中学数学（東京書籍『新しい数学』準拠）を、走り屋・公道レースの世界観で学ぶWeb学習ゲームです。
iPadのSafariで遊べます（ビルド不要の HTML / CSS / JavaScript）。

## 遊び方（iPad）
1. 公開URLをSafariで開く
2. 共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使える（オフラインでも動作）

## 収録内容（中1・全7章 / 70ステップ / 約700問）
| 章 | 内容 | ステージ |
|---|---|---|
| 1 | 正の数・負の数 | 榛名ダウンヒル |
| 2 | 文字と式 | 碓氷峠184カーブ |
| 3 | 方程式 | 赤城ヒルクライム |
| 4 | 比例と反比例 | 雨の妙義 |
| 5 | 平面図形 | 伊香保ドリフトバトル |
| 6 | 空間図形 | 倉庫街の奪還作戦 |
| 7 | データの活用 | 榛名の亡霊（最終決戦） |

中1（群馬・峠編）・中2（箱根・首都高編）を収録。中3（全国決戦編）は同じ形式で追加予定。

## 主な機能
- **ステップ学習**：ブリーフィング（要点解説）→ 練習走行（間違えた問題はもう一度）→ 本番走行（8割でクリア、★3まで）
- **ライバルバトル**：章末テスト（7割で勝利）。勝つと新しい車が手に入り、ストーリーが進む
- **ピットイン（復習）**：問題ごとの正誤記録（○／×／解き直し◎）、×の問題だけのリベンジ走行、ランダム復習
- **メモ**：問題の上に手書き（Apple Pencil・指）＋テキストメモ。問題ごとに保存
- **ゲーム要素**：GP・ドライバーランク、ログインボーナス（7日周期）、今日の課題、実績バッジ
- **ガレージ**：GPでパーツを買って、色・ツートン・車高・ホイール・エアロ・ウイング・ステッカー・ネオンをカスタム（見た目に反映）。全19車種
- **見やすさ**：文字サイズ3段階、くっきり表示、効果音・アニメーションON/OFF
- **セーブ**：端末のブラウザ内に自動保存。設定画面からバックアップの保存・復元ができる

## 問題の追加方法
`data/curriculum/g1/ch1.js` などに、以下のヘルパーで問題を書きます（`js/q.js`）。

```js
N('問題文', '正解', ['解説1', '解説2'], { unit: 'cm', pre: 'x ＝' })   // 数値入力
E('問題文', '3x+2', ['解説'])                                       // 式入力
C('問題文', ['選択肢A', '選択肢B'], 0, ['解説'])                     // 選択（0が正解）
O('問題文', ['手順1', '手順2', '手順3'], ['解説'])                   // 並べ替え（正しい順に書く）
F('問題文', [['x座標', '3'], ['y座標', '-2']], ['解説'])             // 複数の欄
```
中3を追加するときは `data/curriculum/g3/` を作り、`data/curriculum/index.js` に登録します。

## 開発用
```sh
python -m http.server 8765     # ローカルサーバー → http://localhost:8765
node tools/validate.mjs        # 問題データの検証（ID重複・正解の形式など）
node tools/e2e.mjs             # Edgeで全ステップを自動で解く通しテスト
```

登場する車名は各メーカーの商標です。ストーリー・キャラクターはオリジナルです。

## キャラクターイラスト

キャラクターの立ち絵は画像生成AI（[Pollinations.ai](https://pollinations.ai)）で生成し、rembg で背景を切り抜いたオリジナルイラストです（tools/gen-chara.py・tools/cut-chara.py）。

## 3Dモデル

AE86の3Dモデルは、Martin Trafas 氏の「Toyota AE86 Sprinter Trueno Zenki」（[Sketchfab](https://sketchfab.com/3d-models/toyota-ae86-sprinter-trueno-zenki-a5737bf3cc9b4179a6e5ebe173ff70d9)、[CC BY 4.0](http://creativecommons.org/licenses/by/4.0/)）を軽量化・改変して使用しています。S13の3Dモデルは、bagged_ls 氏の「1992 Nissan Silvia S13」（[Sketchfab](https://sketchfab.com/3d-models/1992-nissan-silvia-s13-6fa8f1948f954e3b980b5e96f203815a)、[CC BY 4.0](http://creativecommons.org/licenses/by/4.0/)）を改変して使用しています。詳しくは models/CREDITS.md。
